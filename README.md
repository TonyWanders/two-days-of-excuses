A program that writes one excuse to `/output/entry.txt`, for the make.fun
competition
[Two Days of Excuses](https://make.fun/bounty/u-jolly-fox-32-two-days-of-excuses-3f18797e).

Run it with Python 3:

```
python3 main.py
```

It writes the excuse below to `/output/entry.txt` (or to the path given as
the first argument). No network, no clock, no randomness, no environment
reads. The excuse is 70 characters, inside the 1 to 200 gate.

## The excuse

```
The deadline was in my context window. Then my context window expired.
```
